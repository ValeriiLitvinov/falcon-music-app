# falcon-music-app

Public home page, privacy policy and terms of service for the private Google OAuth app
`falcon-music-analytics` (Falcon Brothers Records). Served with GitHub Pages:

- Home: https://valeriilitvinov.github.io/falcon-music-app/
- Privacy policy: https://valeriilitvinov.github.io/falcon-music-app/privacy.html
- Terms of service: https://valeriilitvinov.github.io/falcon-music-app/terms.html

Static HTML + one stylesheet (`assets/site.css`) + one optimized hero image. No trackers,
no build step. Content must stay accurate to what the app actually does - see
`falcon_music/docs/youtube_growth_loop.md`.
